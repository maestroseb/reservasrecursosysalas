Activar Sistema

Sigue estos 4 pasos

1

Abrir Apps Script

En el menú superior, ve a:

Extensiones → Apps Script
2

Activar API de Apps Script

Para recibir actualizaciones automáticas del sistema, activa la API:

Abre script.google.com/home/usersettings
Activa el interruptor de "API de Google Apps Script". Esto solo se hace una vez y permite que el sistema se actualice automáticamente cuando haya mejoras.
3

Crear Implementación

Haz clic en el botón azul:

Implementar → Nueva implementación

⚙️ Configura así:

  • • Tipo: Aplicación web
  • • Ejecutar como: Yo
  • • Acceso: Cualquier usuario
4

Copiar y Abrir

Google te dará una URL (enlace web).

Copia esa URL, abre una pestaña nueva en tu navegador y pégala allí.

Al abrir el enlace, verás el asistente final para crear las pestañas y configurar tu cuenta de Admin automáticamente.
